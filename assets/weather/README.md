# 当前天气图标

这组图标于 2026-10-07 为 MoonE-ink 以 SVG 基础形状和路径手工编码绘制，未复制第三方图标、字体或图片。用途是替换天气版式右上方的固定装饰云团，按**当前天气**显示对应图标；它不代表三日预报中的任意一天，也不从正文猜测天气。

| 文件 | 天气 |
| --- | --- |
| `clear.svg` | 晴，太阳图形，适用于白天 |
| `clear-night.svg` | 晴夜，月亮图形 |
| `cloud-sun.svg` | 晴间多云，太阳图形，适用于白天 |
| `cloud-moon.svg` | 夜间晴间多云，月与云 |
| `cloud.svg` | 多云 |
| `overcast.svg` | 阴 |
| `rain.svg` | 雨 |
| `snow.svg` | 雪 |
| `storm.svg` | 雷雨 |
| `fog.svg` | 雾 |
| `unknown.svg` | 未提供或不支持的当前天气 |

统一透明背景、`viewBox="0 0 96 96"`；建议显示尺寸为 92 × 92 px。每个文件包含中文 `<title>`，不依赖外部字体或图片。`clear` / `cloud-sun` 表示日间，`clear-night` / `cloud-moon` 表示夜间，由调用方在 `wxToday.sky` 中显式选择；不根据本机时钟或正文推断昼夜，不接外部天气服务。未知值或缺失实况使用 `unknown`，不能把太阳图标当作昼夜通用标记。

轮廓使用 `#333333`、2.2 单位圆角描边；少量雾线为 3.4 单位。平涂与内线使用 `#666666`、`#888888`、`#BBBBBB`、`#DDDDDD`，均为中性灰且处于 16 阶灰度值（17 的整数倍）上。无渐变、模糊、阴影、抖动或噪点。透明区域由版式纸色填充，栅格化边缘仍会产生正常抗锯齿，应通过正式渲染链路量化为设备灰阶。
